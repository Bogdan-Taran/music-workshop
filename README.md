# MusicTagger — музыкальная мастерская

Единое приложение для скачивания с YouTube и Яндекс Музыки, редактирования тегов и обложек. Русский интерфейс, Windows и macOS. Поддерживает MP3, FLAC, M4A без DRM, OGG Vorbis и Opus. Можно править одну песню или несколько, назначать общую обложку и сохранять копии в новую папку с понятными именами.

## Запуск на Mac

1. Установите [Python 3.11 или новее для macOS](https://www.python.org/downloads/macos/) через официальный macOS installer с Tk.
2. Распакуйте архив целиком в обычную папку.
3. Дважды нажмите `start_macos.command`. При первом запуске нужен интернет для установки библиотек.

Лаунчер находит Python из Finder и создаёт отдельное окружение `.venv-macos`. Старый Python от Apple с Tk 8.5 не используется. Окно Терминала оставьте открытым до выхода из приложения.

Для обычного приложения запустите `build_macos.command`. Результат — `dist-macos/MusicTagger.app`. Перенесите его целиком в «Программы». Python для запуска собранного приложения не требуется. Сборка выполняется на вашем Mac для архитектуры установленного Python. Готовая `.app` в архив не включена.

Если при распаковке потерялись разрешения на запуск, откройте Терминал в папке приложения:

```sh
chmod +x start_macos.command build_macos.command update_macos.command
./start_macos.command
```

## Запуск на Windows

1. Установите [Python 3.11 или новее](https://www.python.org/downloads/) с Tcl/Tk и включённым Add Python to PATH.
2. Распакуйте архив целиком.
3. Откройте `start_windows.bat`. При первом запуске библиотеки установятся через интернет.

Для самостоятельного EXE после первого запуска откройте `build_windows.bat`. Результат — `dist/MusicTagger.exe`; ему не нужен Python. Сборка выполняется на Windows. Готового EXE в архиве нет.

## Три вкладки — один рабочий процесс

### 1. Скачивание

Вставьте одну или несколько ссылок (по одной на строку) и нажмите **«Добавить в очередь»**. Сервис определяется автоматически: YouTube либо Яндекс Музыка. Поддерживаются Markdown-ссылки `[текст](ссылка)`, лишние обратные слеши перед `?`, `&`, `=` и ссылки с рекламными параметрами. Ссылки на один и тот же трек/ролик не дублируются в очереди.

Выберите папку и нажмите **«Скачать очередь»**. По умолчанию музыка сохраняется в `Music/MusicTagger/Загрузки` в домашней папке. YouTube преобразуется в MP3 без видеодорожки; Яндекс скачивается как MP3 с наибольшим доступным битрейтом. Название и доступные сведения об исполнителе/альбоме записываются в теги. Ссылка на источник записывается в комментарий.

Скачивание работает в фоне. Можно переключиться на редактор и править уже добавленную музыку. Ошибка одного файла не останавливает остальные: выберите строку, чтобы увидеть причину, или дважды щёлкните для полного сообщения. «Повторить выбранные» возвращает ошибочные/отменённые строки в очередь и запускает ожидающие загрузки. «Убрать выбранные» удаляет только строки, а не файлы на диске.

**«Отменить»** останавливает текущий файл и оставшуюся очередь. Уже готовые файлы остаются; незавершённый удаляется. Ожидающие строки можно продолжить кнопкой «Скачать очередь». Отменённую текущую строку можно повторить отдельно. При медленном сервере отмена дождётся завершения или таймаута сетевого запроса.

По умолчанию готовые файлы **автоматически добавляются в «Теги и обложки»**. Снимите галочку, если нужен только загрузчик. Чтобы перейти к конкретным файлам, выделите готовые строки и нажмите **«Открыть выбранные в редакторе →»**. Один и тот же файл не создаёт повторных строк в редакторе.

Очередь и черновики тегов хранятся до закрытия программы. Скачанные файлы и сохранённый вход в Яндекс остаются между запусками. После перезапуска музыку можно открыть через «Добавить песни»/«Добавить папку».

### 2. Теги и обложки

Редактируйте скачанные файлы либо добавьте свои. Для каждой песни можно задать отдельное название; для нескольких — общие теги и одну обложку. Внизу этой вкладки находятся папка экспорта, правила именования и кнопка **«Сохранить копии»**. Подробности ниже.

Папка скачивания и папка экспорта — разные этапы. Скачанные MP3 остаются как исходники, версии с вашими правками сохраняются копиями. Экспорт берёт все строки редактора на момент нажатия; музыка, скачанная уже во время экспорта, будет включена в следующий экспорт.

### 3. Аккаунт Яндекса

Нажмите **«Войти / сменить аккаунт»**. Приложение покажет короткий код и кнопку «Открыть Яндекс». Откройте страницу, введите код и подтвердите вход в браузере. Пароль в приложение вводить не нужно. После подтверждения аккаунт сохраняется для следующих запусков. Если вы начали скачивание Яндекса без входа, эта вкладка откроется автоматически; после подтверждения загрузка продолжится.

Вход хранится отдельно от исходников и `.app`/EXE, поэтому обновление приложения его не удаляет:

- macOS: `~/Library/Application Support/MusicTagger/yandex_account.json`.
- Windows: `%APPDATA%/MusicTagger/yandex_account.json`.
- Linux: `$XDG_CONFIG_HOME/MusicTagger/yandex_account.json` или `~/.config/MusicTagger/yandex_account.json`.

Это локальный файл с токеном, не зашифрованное хранилище; на macOS/Linux создаётся с правами доступа только для владельца. «Забыть аккаунт» удаляет сохранённый вход на этом компьютере. Если токен истёк или отозван, приложение запросит новый вход. При отмене смены аккаунта прежний сохранённый вход остаётся.

**Перенос из старого скрипта:** нажмите «Перенести вход из старого скрипта…» и выберите `.yandex_music_token.json` рядом со старым `download_music.py`. На Mac скрытые файлы в окне выбора показываются сочетанием Cmd+Shift+точка. Исходный файл не меняется. Если срок токена истёк, войдите по коду. При первом скачивании перенесённый вход будет проверен сервисом.

## Что нужно для сервисов

**YouTube:** установите [Node.js 22+](https://nodejs.org/en/download/) либо Deno 2.3+ и перезапустите приложение. FFmpeg и библиотека загрузки устанавливаются вместе с зависимостями; при сборке FFmpeg включается в приложение. Node.js/Deno остаётся внешним компонентом. Это требование [yt-dlp для поддержки YouTube](https://github.com/yt-dlp/yt-dlp/wiki/EJS). Локальному редактору и загрузкам Яндекса Node.js не нужен.

YouTube поддерживает отдельные ролики, `youtu.be`, Shorts и YouTube Music. Ссылка с видео и плейлистом импортирует только указанное видео. Плейлисты целиком, каналы, текущие эфиры и запланированные трансляции не загружаются. MP3 создаётся в VBR с качеством 2; это перекодирование, а не улучшение исходного качества. Временный скачанный файл удаляется после преобразования.

**Яндекс Музыка:** используется [неофициальная библиотека yandex-music-api](https://github.com/MarshalX/yandex-music-api). Поддерживаются отдельные треки `/track/456` и `/album/123/track/456` на доменах music.yandex.ru/com/by/kz/uz. Доступность треков и качества зависит от аккаунта, подписки и сервиса. Альбомы и плейлисты целиком не поддерживаются. MP3 скачивается без перекодирования.

Приватные, удалённые и ограниченные сервисом материалы могут быть недоступны. Приложение не извлекает браузерные cookies. Одинаковые имена файлов получают суффиксы `(2)`, `(3)` и т. д.; готовые файлы не перезаписываются. При штатной отмене и ошибках временные папки удаляются. После аварийного завершения системы могут остаться `.youtube-*` или `.yandex-*` в папке загрузок.

### Обновление

Запустите `update_macos.command` или `update_windows.bat`, затем перезапустите приложение. Если используете собранное `.app` или EXE, повторите сборку. При переходе с предыдущей версии распакуйте весь новый архив; старые исходники не содержат новых вкладок. Сохранённый вход, скачанные песни и экспортированные копии обновление не затрагивает.

## Правка локальных песен и экспорт

- «Добавить песни» — выбор нескольких файлов. «Добавить папку» — файлы прямо в папке, без вложенных каталогов.
- Одна выбранная песня: справа задайте её индивидуальные теги. Черновик меняется сразу; оригинальный файл не записывается.
- Несколько песен: Ctrl/Cmd или Shift, затем «Общие теги…». Меняются только отмеченные поля. Отмеченное пустое поле удаляет соответствующий тег.
- «Обложка для выделенных…» встраивает одну картинку во все выделенные песни. JPEG/PNG/WebP приводится к JPEG не более 1600 × 1600 с сохранением пропорций; прозрачность не сохраняется. «Удалить» убирает все встроенные обложки у выбранных песен.
- «Названия из имён файлов» переносит имя без расширения в тег названия. Кракозябры программа не угадывает: их можно заменить вручную.
- «Сбросить правки» возвращает теги исходного файла. «Убрать из списка» не удаляет файл с диска.
- Внизу выберите место, имя папки и шаблон имени: название; исполнитель — название; номер — название; исходное имя.
- «Сохранить копии» сохраняет **все песни из списка**, не только выделенные. Оригиналы не изменяются. Совпадения имён получают числовые суффиксы, запрещённые символы заменяются подчёркиванием. Если папка уже есть, файлы добавляются в неё.

Доступные поля: название, исполнитель, альбом, исполнитель альбома, год/дата, жанр, номер трека и комментарий. Номер: `3` или `3/12`. Дата: `2026`, `2026-11` или `2026-11-01`. Правки между запусками не сохраняются — перед выходом экспортируйте копии. Повторный экспорт создаёт новые копии.

## Linux

Нужен Python 3.11+ с Tkinter (обычно пакет `python3-tk`).

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python music_tagger.py
```

## Компоненты

[Mutagen](https://mutagen.readthedocs.io/en/latest/) — теги; Tkinter — интерфейс; Pillow — обложки; [yt-dlp](https://github.com/yt-dlp/yt-dlp) и yandex-music-api — скачивание; imageio-ffmpeg — FFmpeg; [PyInstaller](https://pyinstaller.org/en/stable/usage.html) — сборка. WAV, WMA, защищённые M4A и Ogg FLAC не поддерживаются.

## Проверки

Проверены три вкладки на Mac, очередь обоих сервисов, автоматический и ручной перенос файлов, индивидуальные названия, продолжение после ошибки и отмена. Проверены сохранение/перенос/сброс аккаунта на тестовых данных, запись тегов и обложек, выбор качества MP3 и очистка временных файлов. Ранее проверена реальная загрузка YouTube. Реальный вход и скачивание Яндекса с пользовательским аккаунтом не проверялись. Windows и сборки EXE/.app не проверялись.

Автономные проверки: `python -m unittest discover -s tests` из установленного окружения. Ответы сервисов в тестах подменены, а преобразование и запись аудиофайлов выполняются настоящими библиотеками. Тесты не входят в реальные аккаунты.
